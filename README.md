## 🛠️ Core Language Mandates

1. **The Aryabhata Base:** All indexing across arrays, databases, and lists strictly **starts at 0** (universal zero).
2. **The Action Block:** Universal routines must be explicitly declared using the full keyword `function`.
3. **The Class Blueprint:** Objects are built using the `class` keyword and jump straight into `{ }` brackets. **No `:` colon after a class name**.
4. **The Logic Flows:** Loops and structural conditions (`if`, `for`) must use a **`:` colon** to open their execution paths.
5. **The Null Mandate:** Any failed lookup or search query must return `null` (absolute emptiness).
6. **The Natural Connectors:** Joining strings uses `+` for tight joins and `,` for natural spaced joins.
7. **The Terminal Prompt:** The official developer command line shell utilizes the Indian Rupee symbol (**₹**) as its execution prompt.
